# Архив ленты Sports.ru

Локальная веб-форма: новости [Sports.ru](https://www.sports.ru/) по названию тега и датам (в том числе за старые годы).

## Как запустить (Windows)

1. Откройте папку проекта и дважды кликните `start.bat`.
2. Если Python ещё нет, скрипт попробует поставить его сам (через `winget` или скачав установщик с python.org).
3. В браузере откроется http://127.0.0.1:5000/

Либо вручную:

```bash
pip install -r requirements.txt
python app.py
```

Нужен интернет: данные подгружаются с Sports.ru в момент запроса.

## Возможности

- поиск тега по названию (например, «Этери Тутберидзе», «Спартак»);
- фильтр по датам или быстрый выбор года;
- типы материалов: новости, статьи, блоги.

Неофициальный инструмент для личного просмотра публичной ленты.
